# kundali-explorer

An interactive, static website for exploring the twelve bhāvas.
Features
    • Click any of the 12 houses to view its detailed content in the same page.
    • Search the house content.
    • General bhāva reference and classifications.
    • Responsive layout for desktop and mobile.
    • No database, server or build step required to run the site.
